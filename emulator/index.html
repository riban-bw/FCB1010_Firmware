MIDI in

A CC on the pedal's channel that matches a stomp's number sets that stomp (64 and up is on) and lights its LED. Footswitches that share a CC or note share its state, in every bank. Nothing is echoed back out.

How to use

  • Click or touch a footswitch. Keys 1–9, 0 are switches 1–10, ↑ and ↓ are UP and DOWN.
  • Hold a stomp for over 1s to see the momentary behaviour. Hold UP or DOWN for 400 ms to start the 4 Hz auto-repeat, which speeds up to 20 Hz after about 4 s and stops at 0 and 127; the program change goes out on release.
  • For UP + DOWN together use the button under the unit, or hold both arrow keys.
  • In config mode UP and DOWN change the page; hold UP (or UP + DOWN) for 1s to save and leave, hold DOWN for 1s to cancel.
  • Settings are saved in this browser, like the pedal's EEPROM. Power cycle reloads them.

Footswitches

ModeMessageNumberON ValueOFF Value

These are the footswitches of the bank shown; choosing another bank switches the pedal to it (as UP / DOWN do while DIRECT SELECT is dark) and drops changes to the old bank that were not stored. For a program change, ON value is the program sent when the switch turns on and OFF Value the one sent when it turns off (Number is not used); with both the same it is one program, sent on every press.

Calibration (raw heel–toe): –

Changes go to the pedal at once and work straight away; Store keeps them in its EEPROM. A MIDI output to the pedal is enough to change settings, load a file and store; the input from the pedal is only needed to read it (Read, Find). Until you read the pedal, the panel shows the emulator's settings, or whatever you last loaded or changed. "On channel" is the channel the pedal listens on now; "Pedal's MIDI channel" changes it. Save to file and Load from file keep settings on this computer (everything but the calibration, which belongs to each pedal); loading sends them to the pedal, and Store then keeps them. The pedal takes MIDI settings in run mode only, on its own channel, as NRPN controllers (no SysEx). A real pedal needs a MIDI interface in both directions, and a browser with Web MIDI (Chrome or Edge; the page must be a local file or a secure site).
